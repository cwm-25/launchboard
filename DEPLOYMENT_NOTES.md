## Backend (Render.com) — DEPLOYMENT GUIDE

| Property | Value |
|----------|-------|
| **Platform** | Render.com Free Tier |
| **Runtime** | Python 3.11 |
| **Framework** | FastAPI + Uvicorn |
| **Database** | SQLite (file-based, no external DB needed) |
| **Repo** | https://github.com/cwm-25/launchboard |

### Step 1: Create Render Account
1. Go to https://render.com
2. Sign up (GitHub login recommended — same account: cwm-25)
3. No credit card required for free tier

### Step 2: Create New Web Service
1. Dashboard → **New +** → **Web Service**
2. Connect your GitHub repo: `cwm-25/launchboard`
3. Configure:
   - **Name**: `launchboard-backend`
   - **Runtime**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `cd backend/launchboard && uvicorn main:app --host 0.0.0.0 --port $PORT`
   - **Plan**: Free
4. Add Environment Variable:
   - `DATABASE_URL` = `sqlite:///./launchboard.db`
5. Click **Create Web Service**

### Step 3: Wait for deploy
- Render will auto-build and deploy from your GitHub repo
- First deploy takes ~2-3 minutes
- URL will be: `https://launchboard-backend.onrender.com`

### Step 4: Verify health endpoint
```bash
curl https://launchboard-backend.onrender.com/api/health
```
Expected: `{"status":"ok","database":"connected"}`

### Step 5: Update frontend if backend URL differs
If Render assigns a different URL, update `frontend/api.js`:
```js
// Production backend
return 'https://YOUR-ACTUAL-URL.onrender.com/api';
```
Then re-deploy frontend:
```bash
cd frontend && vercel --prod --yes
```

## Known Limitations

| Issue | Notes |
|-------|-------|
| SQLite on Render | File persists across deploys but not across service deletion. Use PostgreSQL for production data durability |
| Free tier sleep | Render free tier spins down after 15 min inactivity. First request after idle may take 30s to wake up |
| No auth | By design for MVP — single user only |
